# Парсер шуруповёртов Makita

Собирает данные с сайта ВсеИнструменты.ру
через Firefox с помощью Python и Selenium.

## Что сохраняется

- Модель.
- Цена.
- Ссылка на товар.
- Оценка.
- Количество отзывов.

Результат — `makita_spb.csv`.
В таблицу включаются товары с подтверждённым наличием.

## Установка

Нужны Python и Firefox.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск

```powershell
.\.venv\Scripts\python.exe parse_makita.py
```

В открывшемся Firefox выберите Санкт-Петербург,
прокрутите каталог до конца и дождитесь загрузки товаров.
Затем введите `Санкт-Петербург` в терминале и нажмите Enter.

## Важно

Собирается только текущая страница каталога.
Тип питания отдельно не проверяется.
При успешном сохранении предыдущий CSV перезаписывается.
